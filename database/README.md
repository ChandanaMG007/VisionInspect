# VisionInspect - Database Layer

This directory is designated for PostgreSQL database migrations and schema definitions.

### Planned Tables:
1. `products`: Catalog of inspected product models and specifications
2. `inspections`: Individual inspection runs, timestamps, MSE errors, anomaly scores, and recommendations
3. `defect_categories`: Calibrated defect classes (scratches, cracks, contamination, dimensional flaws)
4. `system_metrics`: Daily/weekly throughput, false discovery rates, and model latency
